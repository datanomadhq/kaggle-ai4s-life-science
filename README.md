# AI4S Open Innovation: AI for Life Science

Work for the Kaggle hackathon [AI4S Open Innovation: AI for Life Science](https://www.kaggle.com/competitions/ai-4-s-open-innovation-artificial-intelligence-for-life-scien) (a track of the 5th Pazhou Algorithm Competition; final deadline 2026-10-10 15:59 UTC).

## Layout

- `reference/`: competition pages (overview, judging criteria, rules)
- `data/`: datasets (gitignored, download locally)

## Deliverables

A Kaggle Writeup with a demo video (max 5 minutes), a public code repository, and a technical report (about 15-20 pages), judged by the organising committee.
